# Aset ornamen undangan

Koleksi bahan PNG master dan WebP:

- `jepun-ivory/`: 2 ornamen khusus tema ivory.
- `puri-emerald/`: 2 ornamen khusus tema emerald.
- `senja-terracotta/`: 2 ornamen khusus tema terracotta.
- `shared/`: 6 ornamen bersama berupa bunga, bingkai, divider, dan gapura.
- `bundles/`: paket ZIP untuk dibagikan.
- `documentation/`: prompt generasi dan panduan penggunaan.

Total 12 desain, masing-masing PNG dan WebP. Folder ini menyimpan bahan desain. Salinan di `public/ornaments/` dipertahankan karena dipakai website dan tautan unduhan yang sudah dibagikan.
