# Enam ornamen tambahan per tema

PNG master dan WebP web-ready. Seluruh aset memiliki alpha transparan; cascade Ivory dan spray Terracotta juga memiliki sapuan warna lembut semi-transparan di sekitar bunga.

Jepun Ivory:
- ivory-jepun-cascade: rangkaian vertikal untuk sisi cover.
- ivory-floral-crescent: bingkai terbuka untuk foto atau nama.

Puri Emerald:
- emerald-gold-fan: aksen emas untuk kepala bagian atau penutup.
- emerald-foliage-corner: rangkaian sudut untuk cover dan kartu.

Senja Terracotta:
- terracotta-floral-spray: bunga hangat untuk sisi foto atau cerita.
- terracotta-meadow-border: pembatas bawah untuk penutup undangan.

Pertahankan proporsi gambar. Gunakan satu elemen dominan per bagian dan sisakan ruang dari teks. File ini bahan desain baru; belum mengubah susunan template website. Prompt lengkap ada di PROMPTS.md.
