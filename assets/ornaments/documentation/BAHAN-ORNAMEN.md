# Bahan ornamen Bali — Temu

Tiga aset tambahan hasil generasi AI, masing-masing tersedia sebagai PNG master dan WebP untuk website. Seluruh file memiliki alpha transparan; bingkai floral memiliki sapuan warna lembut semi-transparan di sekitar daun.

- jepun-bouquet: rangkaian diagonal untuk sudut cover, kartu, dan galeri.
- floral-arch: bingkai vertikal untuk foto atau nama; tempatkan tulisan di bagian tengah yang kosong.
- jepun-divider: pemisah horizontal antarbagian.

Gunakan satu ornamen dominan per area, pertahankan rasio gambar, dan beri jarak dari teks. Palet ivory, sage, dan champagne serasi dengan Jepun Ivory, Puri Emerald, dan Senja Terracotta. Ini ilustrasi artistik, bukan dokumentasi motif sakral tertentu.

Prompt dan mode generator tersedia di PROMPTS-ADDITIONAL.md. File PNG asli tidak ditimpa; WebP adalah versi kompresi dengan alpha dipertahankan.
